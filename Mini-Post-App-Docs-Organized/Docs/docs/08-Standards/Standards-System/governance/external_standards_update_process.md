## External Standards Update Mechanism

When an adopted framework (ISO, NIST, WCAG, or social platform API rules) is updated:
1. Flag affected internal standard records in `src/standards/`.
2. Identify dependent validators and StudioOS orchestration rules.
3. Review and update mapping evidence in `master_alignment_matrix.md`.
4. Update `reviewedDate` and increment standard version.
