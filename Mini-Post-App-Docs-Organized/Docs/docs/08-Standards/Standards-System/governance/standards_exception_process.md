## Controlled Exception Workflow

Every exception to an internal or adopted standard requires:
1. Exception ID & Affected Standard
2. Business/Technical Rationale
3. Risk Assessment & Mitigation Controls
4. Named Owner & Approval Authority
5. Expiry Date & Review Date
