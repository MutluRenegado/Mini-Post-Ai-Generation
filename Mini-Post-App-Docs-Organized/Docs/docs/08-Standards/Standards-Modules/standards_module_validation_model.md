## 1. Validation Engine Overview

The Standards Module provides a multi-stage validation framework for content generated or published within Mini Post App.

### Validation Pipeline Stages

1. **Pre-Generation Validation**:
   - Prompt structure check (`Prompt Standard`)
   - Platform limit verification (`Social Platform Standards`)
2. **AI Output Scrutiny**:
   - Tone, grammar, and readability scoring (`AI Writing Standard`)
   - Character count and thread structure check (`X Standard`, `LinkedIn Standard`)
3. **Media & Visual Validation**:
   - Image aspect ratio & resolution check (`Image Standard`, `Sizing Standard`)
   - Color contrast & accessibility check (`Color Standard`, `Accessibility Standard`)
4. **Pre-Publishing Inspection**:
   - Hashtag validation (`Hashtag Standard`)
   - Schedule collision detection (`Scheduling Standard`)
   - Platform policy compliance (`Content Policy Standard`)
