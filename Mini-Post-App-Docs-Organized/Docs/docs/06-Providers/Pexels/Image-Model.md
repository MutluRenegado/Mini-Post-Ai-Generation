## Provider Image Model Mapping

Pexels photos normalize directly into the project's standard [Canonical-Image-Model.md](../Canonical-Image-Model.md).

All asset instances generated by `PexelsProvider` contain complete width, height, photographer credit, thumbnail URLs, and source URLs. Imported assets retain mandatory unreviewed status (`rightsConfirmed: false`, `commercialUseReviewStatus: 'PENDING'`).
