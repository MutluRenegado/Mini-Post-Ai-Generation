# Pexels Attribution — Mini Post App

Status: **Verified Attribution Specification**

---

## Attribution Requirements

1. **Photographer Credit**: Extracted from `photo.photographer`.
2. **Profile URL**: Extracted from `photo.photographer_url`.
3. **Attribution String**: `Photo by [Photographer Name] on Pexels`
4. **Attribution URL**: `photo.url` (Pexels asset page).
5. **Persistence**: Preserved across search results, selective import payloads, and Asset Library entries.
