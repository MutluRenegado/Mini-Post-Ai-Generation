# Unsplash Attribution — Mini Post App

Status: **Mandatory Planned Requirement**

---

## Mandatory Photographer & UTM Link Standards

1. **Photographer Display Name**: Extracted from `user.name`.
2. **Profile URL with UTM Parameters**: `https://unsplash.com/@${user.username}?utm_source=mini_post_app&utm_medium=referral`
3. **Unsplash Home Link with UTM Parameters**: `https://unsplash.com/?utm_source=mini_post_app&utm_medium=referral`
4. **Attribution String**: `Photo by [Photographer Name] on Unsplash`
