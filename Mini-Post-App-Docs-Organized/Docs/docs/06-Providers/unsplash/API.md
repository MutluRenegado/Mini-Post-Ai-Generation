# Unsplash API Specification — Mini Post App

Status: **Planned API Integration**  
Upstream Base URL: `https://api.unsplash.com/`

---

## Integrated Endpoints

- **Search Photos**: `GET /search/photos`
- **Get Single Photo**: `GET /photos/:id`
- **Trigger Download**: `GET /photos/:id/download` (or `links.download_location`)
