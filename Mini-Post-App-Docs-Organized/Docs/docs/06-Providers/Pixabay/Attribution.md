# Pixabay Attribution — Mini Post App

Status: **Planned Attribution Standard**

---

## Attribution Requirements

1. **Contributor Name**: Extracted from `hit.user`.
2. **Profile Link**: Extracted from `https://pixabay.com/users/${user}-${user_id}/`.
3. **Source Page**: `hit.pageURL`.
4. **Attribution String**: `Image by [Contributor Name] from Pixabay`
