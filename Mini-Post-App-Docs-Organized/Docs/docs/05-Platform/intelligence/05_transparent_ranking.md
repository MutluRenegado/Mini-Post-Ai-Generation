# Transparent Multi-Component Ranking Engine

The ranking engine calculates 27 explicit component score details (`rawScore`, `weight`, `weightedScore`, `evidence`, `explanation`).

Returns:
- Raw score
- Final score
- Ranking version (`2.0.0-metadata-transparent`)
- Rank position
- Selection status (`TOP_MATCH`, `QUALIFIED`, `DISQUALIFIED`)
- Human-readable explanation
