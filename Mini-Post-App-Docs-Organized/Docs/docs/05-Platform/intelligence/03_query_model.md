# Typed Retrieval Query Model

The core platform query model (`VisualReferenceQuery`) encapsulates:
- subject, topic, industry, category, scene
- subjects, people, roles, actions, objects, environment
- visualStyle, lighting, composition, cameraAngle, mood, colors
- orientation, aspectRatio, intendedUse
- organizationId, userId, campaignId, visibilityScope
- excludedReferenceIds, recentlyUsedReferenceIds
- explicit constraints (REQUIRED, PREFERRED, AVOID)

Zero social-network-specific or application-specific fields exist in the core engine.
