## Review Status Lifecycle

- **`PENDING`**: Default state upon upload or import. Cannot enrich production prompts.
- **`APPROVED`**: Image verified for quality, prompt suitability, and confirmed rights. Available for Visual Intelligence retrieval.
- **`REJECTED`**: Failed quality, prompt suitability, or rights criteria. Retained for audit and duplicate checking, excluded from retrieval.
- **`NEEDS_CHANGES`**: Requires additional metadata, cropping, or rights documentation.
- **`ARCHIVED`**: Administratively retired reference image.
