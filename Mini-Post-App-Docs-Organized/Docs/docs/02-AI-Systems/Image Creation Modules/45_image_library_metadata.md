## Metadata Editor & Classification

- **Automatic Verifiable Metadata**: `originalFileName`, `mimeType`, `fileSizeBytes`, `width`, `height`, `aspectRatio`, `orientation`, `checksum`, `perceptualHash`, `uploadDate`.
- **Manual / Suggested Metadata**: `industry`, `topic`, `category`, `scene`, `subjects`, `peoplePresent`, `professionalRoles`, `objects`, `photographyStyle`, `lighting`, `cameraAngle`, `composition`, `mood`.
- **Classification State**: Initial uploads marked `classificationState = 'SUGGESTED'`. Once edited and saved by an admin, state transitions to `'MANUALLY_REVIEWED'`.
