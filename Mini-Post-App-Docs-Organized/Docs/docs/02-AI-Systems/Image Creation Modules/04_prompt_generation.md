## Prompt Structure & Negative Constraints

`ImagePromptBuilder` constructs prompts exclusively from `PostVisualBrief`.

### Negative Constraints Applied:
`no text, no letters, no readable words, no gibberish typography, no logos, no watermarks, no icons, no diagrams, no abstract glyphs, no malformed documents, no distorted hands, no duplicated people`
