# Domain Rules

The live source of truth is `MASTER_IMAGE_CREATION_RULES.md`. This file is a human-readable index for domain maintainers.

- Trade: people, contracts, payment terms, risk evidence; shipping only as context.
- Finance: CFOs and analysts; no money piles or currency rain.
- Technology/AI: engineers and understandable systems; no robots by default.
- Marketing: strategists, campaign materials, audience evidence.
- Healthcare: qualified professionals and appropriate clinical evidence.
- Education: active teaching and learning.
- Manufacturing: process, technical plan, quality evidence.
- Environment design: environment-primary exception allowed only when the topic is explicitly environment-centered.
