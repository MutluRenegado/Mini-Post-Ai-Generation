# StudioOS Version 6.0 — General Availability (GA) Release Notes

## Release Highlights

StudioOS v6.0 marks the formal transition from development and beta testing into **General Availability (GA)**.

### Platform Capabilities Summary
- **Unified Creator Workspace**: Single sidebar layout connecting Projects, Creator Studio, Pipeline Inspector, Knowledge Studio, Prompt Studio, Publishing, Analytics, and Settings.
- **Global Command Palette (`Ctrl+K` / `Cmd+K`)**: Keyboard-first search across all studio workflows and developer tools.
- **Multi-Platform Dispatcher**: Instant review, scheduling, and publishing to LinkedIn, X (Twitter), Instagram, Facebook, and TikTok.
- **RAG Retrieval & Fact Verification**: Automated source collector, knowledge caching, and fact-checking engines.
- **Multi-LLM Benchmark Lab**: Real-time evaluation comparing Gemini 2.5 Flash, GPT-4o, and Claude 3.5 Sonnet.
- **Enterprise Reliability**: Active prompt injection defense, circuit breaker fault recovery, and health probe API (`/api/health`).
