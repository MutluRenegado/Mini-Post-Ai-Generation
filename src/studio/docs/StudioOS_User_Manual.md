# StudioOS Version 3.0 — User Manual & Operations Guide

## Getting Started

1. **Accessing the Workspace**: Open StudioOS and press `Ctrl+K` (or `Cmd+K`) anytime to bring up the Global Command Palette.
2. **Creating a New Post**: Navigate to **Creator Studio** or click **+ New Post Workflow** in the home dashboard.
3. **Inspecting Generation Telemetry**: Open **Pipeline Inspector** to review latency, token usage, and quality scores for all 9 execution stages.
4. **Managing Knowledge & Prompts**: Use **Knowledge Studio** for domain facts and **Prompt Studio** for versioned prompt templates.
5. **Publishing**: Move approved posts to the **Publishing Center** to review, schedule, or dispatch to LinkedIn, X, Instagram, Facebook, and TikTok.
